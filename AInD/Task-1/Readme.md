This folder contains my task 1 code for IEMCT AI and development domain which is to create a mini project in which, I create a student 
expenses tracker. This takes various input factors like amount credited by parents as actual credit, the expenses we spend actually and
also takes amount which we split with our friends. 
Like suppose if we are in a restaurant with our friends and we pay the bill later we split it and amount gets credited to us.
So, as students we need to know actual amount our parents sent to us and how much we are actually spending.
So this tracks our actual credit and also tell actual expenses we spent by deducting those all splits.
This is useful cause when we track our expenses in usual upi apps it directly include all deposits and credits we do from our upi account.
For improvements, you could store the data in a file so it doesn't reset when the program is restarted, add dates/categories for
transactions, and maybe use a menu-driven approach instead of taking all inputs at once. 
Later on, you could also use pandas to generate monthly summaries and average spending stats.
It is just a basic start and used for submission.
